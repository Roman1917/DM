# DMarket Target Bot (Node.js)

Бот для DMarket API, который:

1. Сканирует маркет и находит потенциально выгодные предметы.
2. Создает таргеты на покупку.
3. Каждые 15 минут обновляет свои таргеты.
4. Проверяет, на первом месте ли ваш таргет (по цене относительно `Orders.BestPrice`).
5. Если вас перебили — пересоздает таргет с новой ценой.
6. Учитывает комиссию продажи **2%** при расчете ожидаемой прибыли.

## Логика отбора выгодных предметов

Для каждого title бот берет:

- `Offers.BestPrice` — лучшая цена продажи (ask),
- `Orders.BestPrice` — лучшая цена покупки (bid),
- `Offers.Count` / `Orders.Count` — грубая оценка ликвидности.

Далее:

1. Строит ожидаемую цену быстрой перепродажи:
   - `expectedSell = bestAsk * (1 - quickSaleDiscountPct)`.
2. Учитывает комиссию DMarket на продажу:
   - `netSell = expectedSell * (1 - 0.02)`.
3. Вычисляет максимально допустимую цену покупки по двум ограничениям:
   - минимальная абсолютная прибыль (`MIN_PROFIT_USD`),
   - минимальный ROI (`MIN_ROI_PCT`).
4. Ставит целевую цену таргета:
   - обычно `bestBid + bidStep`,
   - но не выше рассчитанного лимита прибыльности.
5. Отсеивает неликвидные/слабые варианты по фильтрам:
   - минимальный спред,
   - минимальный ROI,
   - минимальная прибыль,
   - минимальное число офферов/ордеров,
   - диапазон цен.

## Как проверяется "первое место" по таргету

Для каждого управляемого ботом таргета:

- если `myTargetPrice >= Orders.BestPrice`, считаем, что таргет в топе;
- если `myTargetPrice < Orders.BestPrice`, бот считает, что вас перебили, и пересоздает таргет с новой ценой (если это все еще выгодно).

> В API нет отдельного `edit` для таргетов, поэтому используется связка `delete + create`.

## Ограничение бюджета и количества таргетов

Бот:

- не выходит за `STRATEGY_MAX_BUDGET_USD`,
- использует только долю баланса `STRATEGY_BALANCE_USAGE_RATIO`,
- ограничивает количество своих таргетов `STRATEGY_MAX_MANAGED_TARGETS`,
- ограничивает новые таргеты за цикл `STRATEGY_NEW_TARGETS_PER_CYCLE`.

## Установка

```bash
npm install
```

## Настройка

1. Скопируйте пример:

```bash
cp .env.example .env
```

2. Заполните:

- `DMARKET_API_KEY`
- `DMARKET_SECRET_KEY`
- при необходимости `DMARKET_AUTHORIZATION`

3. Проверьте торговые параметры стратегии в `.env`.

## Запуск

```bash
npm start
```

По умолчанию в `.env.example` включен `BOT_DRY_RUN=true`, то есть бот только логирует действия без реальных запросов на создание/удаление таргетов.  
Для реальной торговли переключите `BOT_DRY_RUN=false`.

## Тесты

```bash
npm test
```

## Структура проекта

- `src/dmarketClient.js` — подпись запросов и работа с DMarket API.
- `src/strategy.js` — отбор выгодных предметов и планирование действий.
- `src/bot.js` — основной цикл (каждые 15 минут).
- `src/stateStore.js` — локальное состояние управляемых таргетов.
- `.env.example` — пример конфигурации.
